File Specification & Rules
Required CSV Column Headers:
facultyId,fullName,email,phoneNumber,department,designation
  • facultyId: Unique alphanumeric faculty identifier (e.g. FAC101).
  • fullName: Complete name with title (e.g. Dr. Ananya Sharma).
  • email: Valid email address. A corresponding user login account will be automatically provisioned.
  • department: Academic department code or name (e.g. MCA, CSE). Must exist in the database.
  • phoneNumber: Optional 10-digit mobile number.
  • designation: Optional role designation (e.g. Professor, Associate Professor).
Secure Provisioning: Each imported faculty member will automatically receive a user account with ROLE_FACULTY and a secure default password: Faculty@123.
