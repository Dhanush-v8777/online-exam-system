CSV Format Specification
Supported Column Headers:
fullName,emailAddress,password,userRole
  • fullName: User's complete legal name (e.g. Ananya Sharma).
  • emailAddress: Valid email address (e.g. ananya.sharma01@example.com). Checked case-insensitively against existing accounts.
  • password: Temporary password (min 6 characters). Hashed using Spring Security BCrypt before saving.
  • userRole: System role: FACULTY, COORDINATOR (or EXAM_COORDINATOR), or ADMIN.
Duplicate-Safe Import: If an email already exists in the database or appears multiple times in the file, that record is skipped safely. All other valid records continue importing without interruption.
