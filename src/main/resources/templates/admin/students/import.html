CSV Format Specification
Supported Column Structure:
registerNumber,fullName,email,department,semester
Example Rows:
MCA001,Student One,student1@example.com,MCA,1
MBA001,Student Two,student2@example.com,MBA,1
CSE001,Student Three,student3@example.com,CSE,2
  • registerNumber: Unique student register identifier (e.g. MCA001).
  • fullName: Complete student name (e.g. Student One).
  • email: Optional student email. Validated for standard format and duplicate constraints.
  • department: Academic department code or name (e.g. MCA, MBA, CSE). Matched safely against existing departments in MySQL (case-insensitive).
  • semester: Valid semester number between 1 and 8.
Duplicate & Constraint Protection: Existing students are never deleted or overwritten. Duplicate register numbers or emails are safely skipped, allowing valid records from all departments to import smoothly.
